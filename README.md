# dio-desafio-html
Primeiro desafio de projeto do curso de HTML da Digital Innovation One (DIO)

Projeto desenvolvido como parte do curso de HTML na plataforma da [Digital Innovation One (DIO)](https://dio.me).

- Utilização de títulos, parágrafos, listas e links
- Boas práticas de organização de código
