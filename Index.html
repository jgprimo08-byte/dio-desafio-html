O que é HTML?

Se a gente for comparar um site com uma casa, o HTML é a estrutura de tijolos e vigas. Ele não serve para deixar as coisas bonitas (isso é trabalho do CSS) e nem para criar funcionalidades complexas ou lógica (isso fica com o JavaScript).

O HTML serve puramente para organizar o conteúdo. Ele diz para o navegador onde fica o título, onde começa um parágrafo, onde entra uma imagem ou onde fica um link para outra página.

Como funcionam as Tags?

No HTML, a gente escreve quase tudo usando tags. Uma tag é basicamente uma instrução envolvida por sinais de menor e maior.

A maioria das tags precisa de uma abertura e de um fechamento para o navegador saber onde o elemento começa e onde ele termina. A tag de fechamento tem sempre uma barra.

Por exemplo: para criar um parágrafo, a gente abre a tag, escreve o texto e depois fecha a tag com a barra.

O esqueleto de uma página

Toda página HTML precisa de uma estrutura padrão para funcionar direito no navegador:

  • A indicação do HTML5 no topo para o navegador saber a versão moderna.
  • A tag html principal que abraça todo o nosso código.
  • A cabeça da página (head), onde ficam as configurações invisíveis, como a acentuação correta e o título da aba.
  • O corpo da página (body), que é onde fica todo o conteúdo visual que o utilizador realmente enxerga.

As tags que mais vamos usar

Títulos

A gente usa h1 para o título principal da página. Se precisar de subtítulos para organizar os assuntos, vai usando h2, h3 e assim por diante.

Textos e Destaques

Para textos normais usamos a tag p. Quando queremos destacar alguma palavra importante em negrito, colocamos ela dentro de uma tag strong.

Listas

Quando precisamos listar coisas sem ordem específica (com pontinhos), usamos ul com li dentro. Se for uma lista numerada passo a passo, usamos ol.

Links

A tag a é a que cria os links. É com ela que fazemos o utilizador navegar para outro site ou ir para o topo da página.

O que são atributos?

Atributos são informações extras que a gente coloca dentro da tag de abertura para dizer como ela deve se comportar.

Exemplos práticos de atributos:

  • O href na tag de link, que indica o endereço para onde a pessoa vai ao clicar.
  • O id, que dá um nome único para um bloco da página (igual usamos aqui para voltar ao topo).
  • O target="_blank", que faz o link abrir numa aba nova do navegador.

Dicas para não se enrolar no começo

  1. Nunca se esqueça de fechar as tags que abriu. Esquecer uma barra pode bagunçar o layout inteiro.
  2. Preste atenção na acentuação. Sempre configure o charset para UTF-8 no topo do arquivo.
  3. Mantenha o código organizado e espaçado para você não se perder quando o arquivo crescer.
